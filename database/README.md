# Database

## PostgreSQL schema

This project stores evidence management data in PostgreSQL using SQLAlchemy models. The schema includes users, cases, sessions, evidence records, metadata, chain-of-custody entries, verification logs, reports, and audit logs.

## Seed data

Use the SQL scripts in this folder to initialize or seed the database for local development and testing.

## Default local database

- Host: localhost
- Port: 5432
- Database: digital_evidence_db
- User: evidence_app
